\# UOL Help Desk: Implicit Intents Lab Task



A small Android app that lets a student reach the university in one tap.



\## Features

\- Home screen with logo, name field and four buttons

\- Visit Website, Call Help Desk and Find Campus open the browser, dialer and maps app using implicit Intents

\- A safe helper method, openIntent(), shows a Toast if no app can handle the Intent

\- Send a Request validates the name, then opens RequestActivity with an explicit Intent

\- Request screen greets the student and validates a phone number and a web link before opening them



\## How to run

1\. Open this folder in Android Studio.

2\. Wait for Gradle sync to finish.

3\. Run on an emulator or phone.
