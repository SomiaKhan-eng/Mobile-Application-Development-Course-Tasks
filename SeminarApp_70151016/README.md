\# Seminar App



An Android app for registering for a seminar. The student enters a name and email, the app checks they are valid, and a confirmation screen shows the details.



\## Features

\- Registration screen with name and email fields

\- Input validation with a Toast message

\- Confirmation screen that receives the data through an Intent



\## How to run

1\. Open this folder in Android Studio.

2\. Wait for Gradle sync to finish.

3\. Run on an emulator or phone.
